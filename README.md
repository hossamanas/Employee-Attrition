# Employee Attrition Analysis 📊

Employee Attrition Analysis Dashboard built using **SQL Server and Power BI**.

## Project Workflow

- Divided and organized the raw data into multiple tables using **SQL Server**.
- Connected **Power BI** to SQL Server and imported the prepared data.
- Built the data model and created KPIs and interactive visualizations using **DAX**.
- Analyzed employee attrition across departments, job roles, education fields, marital status, and business travel.

## Tools
- SQL Server
- Power BI
- DAX

## Key KPIs
- Total Employees: 1.47K
- Attrition Count: 237
- Attrition Rate: 16.12%
- Average Age: 37
